# Portfolio Projects

This repository showcases a selection of my practical projects in psychology, data analysis, and creative digital tools. Each folder contains a self-contained project with its own description, code, and visual examples.

### 📁 Structure

- `telegram-quiz-bot/` — an interactive Telegram bot quiz with personalized feedback and final message logic. Designed as a playful tool for engagement and gifting hints.
- `data-viz-project/` — statistical analysis of psychological variables (e.g., creativity, national identity, etc.) using Python, and visualized with `matplotlib` and `seaborn`.
- `colab-visualization/`- a final project for the Reuse Science intensive, which includes exploratory data analysis and various types of plots to reveal insights from the data. 

### 🎯 Purpose

This portfolio is intended to demonstrate my applied skills in:
- data structuring and analysis
- creative use of digital tools for psychology and education
- skills at designing simple Telegram bots

Each project reflects a combination of research thinking, technical implementation, and communication clarity.
