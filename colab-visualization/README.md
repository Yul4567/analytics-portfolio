# 📊 Data Visualization with Python — Reuse Science Intensive Final Project (04/2025)

This project was completed as a final assignment for the Reuse Science intensive course in April 2025.
The main goal was to learn and apply data visualization techniques in Python using libraries such as Seaborn and Matplotlib.

The dataset used is the built-in Seaborn dataset exercise, which provides data on physical exercises and pulse frequency.
The project includes exploratory data analysis and various types of plots to reveal insights from the data.

# 📂 Contents:
- 🔍 Data exploration and cleaning
- 📈 Visualizations: scatter plots, box plots, histograms, etc.
- 💡 Insights and conclusions about exercise and pulse data
